SymbolExchange. PHP Tutorials. Simple Input/Output. Algorithms. Strings. Console Application. 
The program swaps the first and last characters of a string entered from the keyboard. 
Developed in the integrated environment Apache NetBeans (in the Microsoft Visual Studio Code editor).

SymbolExchange. Занятия по PHP. Простой Ввод/вывод. Алгоритмы. Строки. Консольное приложение.
Программа меняет местами первый и последний символ строки, ведённой с клавиатуры. 
Разработано в нитегрированной среде Apache NetBeans (в редакторе Microsoft Visual Studio Code).
